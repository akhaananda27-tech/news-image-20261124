A one-image summary of 24 November 2026 world news, built for the [make.fun news-image-20261124 bounty](https://make.fun/bounty/news-image-20261124?ref=jfeejy4f).

`entry.png` is a dense newspaper front page (1024×1024) rendered deterministically by `gen_image.py` (Python + PIL): the ICJ genocide ruling on Myanmar leads, with stories from every region, a markets close and a world-in-brief column.

## Run it

```sh
python3 gen_image.py entry.png
```
